# Project presentation

- [Editable PowerPoint — six slides](VoxelFlight_SIH2026_Presentation.pptx)
- [PDF — six pages](VoxelFlight_SIH2026_Presentation.pdf)

Only the selected six-slide deck is included, in editable and PDF formats. The cover still has explicit team name and ID placeholders pending confirmation.

The deck describes the latest 90-view, source-textured reconstruction and its current stack: COLMAP/PyCOLMAP camera anchors, MapAnything depth inference, Open3D TSDF fusion and source-image texturing. It separately shows the deployed Firebase/FastAPI upload preview so its capabilities are not confused with the saved quality experiment. [Results and experiment comparison](../docs/results.md) retains earlier GPU results for provenance. Neither run establishes ≤1 m surface accuracy or the ten-minute-video processing requirement.

Slides cover project information, proposed solution, technical approach, feasibility, impact and research references. Both files are committed directly to the public repository; no Drive permission is needed to download them.

The PowerPoint retains editable text, architecture connectors and results table, with detailed technical notes and primary sources. Open it in PowerPoint or import it into Google Slides to edit. The PDF is the six-page viewing/submission copy, not an online editor.
