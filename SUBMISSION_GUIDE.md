## Public-access check

Review the repository, PPTX, PDF, screenshots and website while logged out. Downloads should not ask for permission. The public saved workspace must remain reachable without sign-in. New reconstruction may be unavailable if its processing service is down; do not describe a successful saved-demo load as a successful new inference.

## Excluded from GitHub

Private uploads and results, model weights, original dataset archives, caches, credentials, service-account files, SSH keys, environment secrets and existing private Git history.
