Every score below compares the frozen model with data the pipeline never sees: national airborne LiDAR (swisstopo, USGS 3DEP, Austrian BEV) and the Zurich reference camera poses.

SIH specifies spatial accuracy ≤1 m without defining the metric. Model geometry meets it (median). Absolute placement meets it only with the optional RTK/PPK input; consumer GNSS limits it to about 3 m.

ABSOLUTE ACCURACY · RTK

Sub-metre placement with RTK input.

RTK/PPK is an optional input in the problem statement. On a public RTK drone flight (Austria, 176 photos, RTK fixed) the photogrammetric mode placed the model 0.5 m horizontally and 0.41 m vertically from Austria’s official airborne-LiDAR surface model (BEV ALS DSM 2023).
